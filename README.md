# SOWN Focus Manager

Windows desktop utility for grandMA2 onPC focus recovery. Red/black compact UI, Poppins typeface, safe mode by default.

**Experimental:** Test on non-live shows before using with real lighting hardware. The keyboard-focus recovery cannot be validated outside Windows/grandMA2.

Windows installer is built using GitHub Actions and Inno Setup. Go to **Actions → Build Windows Installer** to find an installer artifact after a successful workflow run.
